## §1. Замысел

`_guard_interpreter_matches_main` (`tools/_guards.sh`) — гард, который делает разрыв версий
непредставимым. Внутри него `_interpreter_version_is_sane` проверяет ФОРМУ версии. **Эту проверку
сегодня не держит ни один тест, а `CLAUDE.md` утверждает, что держит.**

Замысел одной фразой: **строка гарда, чьё удаление ничего не краснит, — это либо строка без
теста, либо строка без нужды; и то и другое обязано быть названо, а не описано лучше, чем оно
есть.**

## §2. Измерено, не пересказано (держателем лично, 2026-08-22)

Во временном worktree на приземлённом `76b3d3b`: мутант

```
_interpreter_version_is_sane() { return 0; }
```

(применение подтверждено `grep -c`, `PYTHONDONTWRITEBYTECODE=1`, вычищенный `__pycache__`)
оставляет **весь харнес-сьют зелёным: 248 passed**.

**Причина структурная и она — половина ценности этой карты.** При работе Т-27 этот мутант
СНАЧАЛА ВЫЖИЛ и был закрыт тестом `test_two_undeterminable_sides_refuse_rather_than_agree`. Затем
HIGH-находка Codex про `UV_PYTHON` (коммит `826bd0d`) добавила сравнение выбранного интерпретатора
с пином **выше по потоку** — и оно перехватывает пустую версию раньше, так что названный тест
этого мутанта больше не различает. **Фикс одной находки обесценил пин другой, и обе остались
зелёными.**

## §4. Ловушки

1. **Не «докажи, что мутант умер» — докажи, что умер ЭТОТ мутант.** Тест, краснеющий от какого-то
   другого повреждения гарда, ничего не закрывает: мутант ставится в `_interpreter_version_is_sane`
   и подтверждается `grep -c`.
2. **Не ослабь верхнее сравнение с пином.** Оно закрывает HIGH-находку Codex (`UV_PYTHON`
   перебивает пин). Если для достижимости состояния его придётся переставить — **остановись и
   эскалируй**: порядок этих двух проверок уже оплачен одной находкой.
3. **Fail-closed не должен пострадать.** Живая проба «обе стороны неопределимы → rc 14» обязана
   остаться зелёной; прогони её ДО и ПОСЛЕ.
4. **`CLAUDE.md` правится ровно в том абзаце, который лжёт.** Не расширяй правку на соседние —
   раздел большой и его редактируют параллельные направления.
5. **Мутационная проба** — `PYTHONDONTWRITEBYTECODE=1`, чистый `__pycache__`, `grep -c`
   подтверждает применение. Без этого «мутант выжил» и «мутант не применён» неразличимы.

## §5. Приёмка

1. Мутант `_interpreter_version_is_sane` → `return 0` **краснит названный тест**; проба выполнена
   исполнителем и воспроизводима одной командой из возврата.
2. Проба fail-closed «обе стороны неопределимы» по-прежнему даёт rc 14.
3. `UV_PYTHON`-проба Т-27 по-прежнему ловится (rc 14) — верхнее сравнение не ослаблено.
4. Абзац `CLAUDE.md` соответствует тому, что держат тесты. Если выбран путь (b) — там же написано,
   почему (a) недостижим.
